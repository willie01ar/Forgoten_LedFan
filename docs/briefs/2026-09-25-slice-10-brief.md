# Slice 10 brief — make it behave like a product

**Date issued:** 2026-09-25
**Prerequisite reading:** the slice-9 report, then `docs/decisions.md` **D19, D20, D21** (new)
and **D18**.

## Where we are

The fan works. `HELLO WILLIE` appeared on the blades, upright and readable, and every one of
the 40 reports was echoed back. Milestone 2 is reached and F5 is closed.

What remains is the gap between "it works" and "it behaves". Four items, in this order.

## Task 1 — D21: device removal (fix this first)

After a cable swap the app still says "Connected" and the next Send fails with
`kIOReturnBadArgument`. It is the one bug that makes a working feature feel broken.

**Acceptance**
- [ ] Removal is observed, or `kIOReturnBadArgument` / not-open from `SetReport` is treated
      as a lost connection.
- [ ] Status returns to disconnected and Send disables on its own.
- [ ] The copy says the fan was unplugged, not that the write failed.
- [ ] A test proves a transport reporting that code lands the ViewModel in disconnected.

## Task 2 — D19: Send writes all eight slots

A send defines the fan's whole stored set; unsent slots are cleared. The app must match.

**Acceptance**
- [ ] Send takes all eight persisted drafts and writes all eight, empty ones as blank images.
- [ ] The UI says what Send does — it publishes everything, it does not append one message.
- [ ] Tests cover: all eight written when some are empty, and the packet count matching
      eight images.
- [ ] Golden test extended to an eight-slot send.

## Task 3 — D20: verify the echoes

Every report comes back, with the header's first byte returned as `A1`. Compare each echo to
what was sent.

**Acceptance**
- [ ] Echoes compared; mismatches counted, never aborting the send.
- [ ] `FanStoreReceipt` carries the count and says plainly when every report was confirmed.
- [ ] A test with a stub transport covers all-confirmed and some-mismatched.

## Task 4 — D18: lowercase glyphs

The device's own demo is mixed case. Ours renders `Mom` as `MOM`.

**Acceptance**
- [ ] 5x7 lowercase a-z added to `GlyphFont`; uppercase fallback kept for anything missing.
- [ ] A descender (g j p q y) renders below its neighbours' baseline, not clipped or shifted.
- [ ] Preview screenshot of `*Mom Pick me up @4P*` — the factory demo's own example — in
      `docs/reports/images/`.

## Also

- [ ] `features.md`: close F5, note Milestone 2 reached.

eight messages cycle and the lowercase renders. Fan A only — **fan B stays sealed.**
